# Ibrohimjonov Lazizbek — Interactive 3D WebGL Portfolio & CV

An interactive 3D WebGL developer portfolio featuring an orbital Earth model with global submarine & terrestrial fiber-optic DWDM networks, BGP telemetry console, real-time shaders, and academic engineering metrics.

Live on Vercel: [https://portfolio-ibrohimjonovlazizbek.vercel.app](https://portfolio-ibrohimjonovlazizbek.vercel.app)

## Features
- **Interactive 3D Earth & Atmosphere:** Procedural continental elevation, bathymetry, night lights, and limb Fresnel atmosphere shader.
- **Submarine & Terrestrial Fiber-Optic Network:** 198 fiber strands, 44 global IXP landing hubs, real-time packet pulses, and TeleGeography-accurate maritime waypoint routing.
- **Live BGP Telemetry HUD:** Interactive filtering by network layer (Submarine Trunks, TAS-01 Silk-Optic Backbone, IXP Peering Mesh), Overclock mode, and high-intensity optical gain controls.
- **Performance & Smooth Scroll:** 60 FPS rendering with Three.js r143, Lenis smooth scrolling, and staggered scroll-reveal animations.

## Tech Stack
- HTML5 / CSS3 / JavaScript (ES Modules)
- [Three.js](https://threejs.org/) & custom GLSL Shaders
- [Lenis](https://lenis.darkroom.engineering/) Smooth Scroll
- Google Fonts (Inter & JetBrains Mono)
